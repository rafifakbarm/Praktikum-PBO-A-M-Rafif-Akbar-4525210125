# Profil Organisasi Kampus

## Deskripsi

Proyek ini merupakan halaman profil statis sederhana untuk **BPM FT-KMUP Universitas Pancasila**. Struktur HTML mengikuti materi pertemuan 2: gambar, hyperlink, komentar, atribut, dan tiga jenis list.

## Struktur folder

```text
pertemuan2/
├── css/
│   └── style.css
├── dokumentasi/
│   └── README.md
├── image/
│   ├── rektorat.jpg
│   └── up.jpg
└── index.html
```

## Cara menjalankan

Buka file `html/index.html` menggunakan browser. Tidak memerlukan server atau instalasi tambahan.

## Checklist tugas

- Dua gambar tersedia dan masing-masing memiliki atribut `alt`.
- Link anchor internal tersedia pada navigasi dan tombol halaman.
- Link eksternal tersedia menuju Instagram.
- Link `mailto` tersedia pada bagian kontak.
- Tiga tipe list digunakan: `ol` untuk alur pendaftaran, `ul` untuk program kegiatan, dan `dl` untuk detail singkat organisasi.
- Layout responsif sederhana untuk desktop dan mobile.

## Ringkasan perubahan, masalah, dan solusi

Halaman ini disederhanakan agar sesuai dengan materi HTML lanjutan pada modul, kemudian disesuaikan menjadi profil organisasi kampus BPM FT-KMUP Universitas Pancasila. Struktur utama menggunakan `header`, `nav`, `main`, `section`, dan `footer`. Dua gambar diberi atribut `src`, `alt`, dan `width` agar cara penggunaannya mudah dipahami. Navigasi internal memakai tanda `#`, link Instagram menjadi contoh URL eksternal, dan link email menggunakan skema `mailto:`. Ketiga jenis list diterapkan sesuai fungsinya: `ul` untuk program kegiatan, `ol` untuk urutan pendaftaran anggota, dan `dl` untuk detail organisasi. Tantangan yang ditemukan adalah isi awal masih menggunakan konteks OSIS dan sekolah. Solusinya, seluruh teks diganti menjadi konteks mahasiswa Teknik Informatika, kegiatan kampus, dan Universitas Pancasila. CSS tetap dibuat sederhana dengan warna yang jelas dan media query untuk layar kecil. Komentar HTML dipertahankan untuk menandai bagian penting kode. Dengan susunan ini, source code mudah dibaca dan tetap memenuhi syarat tugas praktikum.
